\begin{center}
    {\bfseries\Large ABSTRACT}
\end{center}
\vspace{0.4cm}

\begin{spacing}{1.25}
Accurate demographic counts are essential for clinical triage and resource allocation in hospital outpatient departments (OPDs). In Ghanaian hospitals, such as Komfo Anokye Teaching Hospital and KNUST University Hospital, pediatric counts remain manual. Cultural carrying practices, such as carrying infants swaddled on mothers' backs, cause severe occlusion and small pixel footprints ($< 32 \times 32$ pixels) in ceiling CCTV feeds. Standard computer vision detectors merge carried infants into caregiver bounding boxes, causing systematic pediatric undercounting.

This thesis formulates and evaluates a privacy-preserving multi-stage computer vision architecture for pediatric person detection, tracking, and demographic occupancy counting in hospital environments. In Stage 1, a full-frame YOLO26s detector extracts person proposals under CLAHE contrast enhancement and SAHI slicing. A ByteTrack tracker maintains identities across frames using an 8D Kalman filter and anatomical seated deduplication. In Stage 2, candidate boxes undergo margin-expanded letterbox cropping ($\alpha = 0.10$, $224 \times 224$ pixels) and pass into a dedicated ONNX crop classifier to estimate raw demographic probabilities. In Stage 3, a multi-modal fusion framework modulates predictions using normalized stature priors ($\theta_{\text{adult}} = 0.32$). It combines weighted temporal smoothing (70\% cumulative history, 30\% rolling window average) with 17-point skeletal cephalocaudal ratio verification ($R_{\text{ceph}} = L_{\text{torso}} / L_{\text{leg}}$).

In comparative benchmark ablations, the fine-tuned detector achieved a peak mAP@50 of $67.1\%$ (mAP@[50:95] of $43.7\%$), outperforming the baseline off-the-shelf detector ($53.4\%$). On a curated 700-frame CCTV evaluation test set across clinical queues, pharmacy lobbies, and classrooms (45 ground-truth individuals), the multi-stage system resolved demographic counts without adult-child identity confusion. On consumer x86 CPU hardware without discrete GPUs, native ONNX FP32 execution with 256-bit AVX2 SIMD instructions achieved $6.8\text{--}8.1$ FPS ($110\text{--}146$ ms latency), running $3.98\times$ faster than emulated FP16. The pipeline outputs anonymous numerical occupancy telemetry designed to interface with hospital management systems without storing facial images. These counts provide objective waiting-area data to support clinical triage workflows.
\end{spacing}
